# Getting started

Everything here is done from **Appearance → Bloqra** and the Site Editor. Budget about ten minutes.

## The theme dashboard

**Appearance → Bloqra** is your starting point. The Dashboard tab gives you six shortcut cards
that jump straight into the right screen of the Site Editor — Styles & Colors, Site Identity,
Header & Footer, Navigation, Templates and Patterns — plus a **Next steps** checklist that ticks
itself off as you complete each item.

## 1. Choose what your homepage shows

Bloqra ships with a designed front page (hero, logo strip, features, highlight, blog and a call to
action). It shows automatically when your homepage is set to display your latest posts, which is
the WordPress default.

To use a static page instead, go to **Settings → Reading** and set **Your homepage displays** to
*A static page*, then pick your page. Your posts move to whichever page you set as the Posts page.

> If you set a static homepage, the designed front page is no longer used. To keep the design,
> either leave the default setting or copy the Bloqra patterns into your static page.

## 2. Add your logo

Open the Site Editor (**Appearance → Editor**), edit the **Header** template part, select the Site
Logo block and upload your logo. A square or wide logo around 200 px tall works well; the header
renders it at 40 px and scales it for retina screens.

Prefer text? Delete the Site Logo block and add a **Site Title** block in its place.

## 3. Add a site icon

The site icon is the small image shown in browser tabs and bookmarks. Set it under
**Appearance → Editor → Styles**, or from **Settings → General → Site Icon**. Use a square image of
at least 512 × 512 px.

## 4. Build your navigation menu

In the Site Editor, edit the **Header** and select the Navigation block. Add pages, custom links or
submenus from the block sidebar.

The same menu is used for the full-screen mobile overlay — there is no second menu to maintain.
The header stays pinned to the top as visitors scroll.

## 5. Make the styles your own

Open **Appearance → Editor → Styles** to switch to one of the four style variations, or to adjust
the palette, typography and spacing yourself. See
[Styles & colors](https://beautifulplugins.com/themes/bloqra/docs/styles-and-colors/).

## Useful plugins

The **Useful Plugins** tab lists free plugins that pair well with Bloqra — including
[Bloqra Blocks](https://beautifulplugins.com/themes/bloqra/docs/bloqra-blocks/) for extra page
building blocks, plus SEO, forms, performance, security and backup picks. Each card installs and
activates without leaving the page.

You are never required to install any of them. Bloqra is standalone.
