# Installation

Bloqra is a free block theme for the WordPress Site Editor. It is free forever, requires no
plugins, and works the moment you activate it.

## Requirements

- WordPress **6.7** or later
- PHP **7.4** or later
- A browser with the block editor enabled (no classic-editor-only setups)

Bloqra is a full site editing (FSE) theme, so WordPress 6.7 is a hard minimum — the Site Editor is
where you will do all of your editing.

## Installing from your dashboard (recommended)

1. Go to **Appearance → Themes → Add New Theme**.
2. Search for **"Bloqra"**.
3. Click **Install**, then **Activate**.

## Installing by upload

1. Download the ZIP from [WordPress.org](https://wordpress.org/themes/bloqra/).
2. Go to **Appearance → Themes → Add New Theme → Upload Theme**.
3. Choose the ZIP, click **Install Now**, then **Activate**.

## After activation

You will see a one-time welcome notice, and a new **Appearance → Bloqra** menu item. That is the
theme dashboard, with three tabs:

- **Dashboard** — shortcuts into the Site Editor and a checklist of setup steps.
- **Useful Plugins** — a curated list of free plugins you can install and activate in one click.
- **Changelog** — what changed in each release, read straight from the theme.

Nothing else is required. The homepage, blog, single post, archive and 404 templates are all
designed already, so your site looks finished before you touch anything.

## Updating

Bloqra updates through WordPress.org like any other theme. When an update is available it appears
under **Dashboard → Updates** and **Appearance → Themes**.

Your content, menus and Site Editor customizations are stored in the database, not in the theme
files, so updates never overwrite your work.

## Removing the theme

Activate a different theme first, then delete Bloqra from **Appearance → Themes**. Site Editor
customizations you made to Bloqra's templates stay in the database in case you switch back.
