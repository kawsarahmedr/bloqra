# Patterns

Patterns are pre-designed sections you drop into a page and edit. Bloqra ships a curated set rather
than a huge library, so everything you insert already matches the rest of the site.

## Inserting a pattern

1. Edit a page or post.
2. Click the **+** button in the top-left toolbar and open the **Patterns** tab.
3. Choose the **Bloqra** category.
4. Click a pattern to insert it, then replace the text and images.

Once inserted, a pattern is just ordinary blocks — nothing stays linked, so edit it freely.

## The pattern library

| Pattern | What it is |
|---|---|
| **Hero** | Large headline, supporting text and call-to-action buttons |
| **Logo Strip** | A row of client or partner logos with a short lead-in |
| **Features Grid** | A grid of icon, title and description cards |
| **Highlight** | An image-and-text section for a single standout point |
| **Call to Action** | A full-width band with a headline and button |
| **Blog Heading** | A section heading for a list of posts |
| **Blog Excerpts** | Posts in a stacked list with excerpts |
| **Posts Grid** | Posts in a card grid with featured images |
| **About Page** | A complete About page layout |
| **Contact Page** | A complete Contact page layout |
| **Sidebar** | Search, recent posts and categories |
| **Comments** | The comments area used on single posts |
| **Post navigation** | Previous and next post links |
| **Header** / **Footer** | The template parts used site-wide |

## Building an About or Contact page

1. Go to **Pages → Add New Page** and give it a title.
2. Open the inserter, choose the **Bloqra** pattern category and insert **About Page** or
   **Contact Page**.
3. Replace the placeholder copy and images, then publish.

For a landing-page look with no title at the top, switch the page to the **Page (No Title)**
template in the editor sidebar.

The Contact pattern is a layout, not a working form — WordPress has no form block of its own. Add
one with a form plugin such as Forming Forms - Form Builder for Block Editor, which is one click away on the **Useful Plugins**
tab of **Appearance → Bloqra**.

## Post formats

Bloqra supports the standard WordPress post formats: aside, gallery, image, link, quote, status and
video. Choose one in the **Post → Format** panel while editing a post.

When a post uses a format other than Standard, the format name is shown alongside the post meta
automatically. Standard posts show nothing extra.

## About the core pattern library

Bloqra replaces the default WordPress pattern library with its own curated set, so the inserter
shows only patterns that fit the theme. Patterns from any plugin you install still appear normally
in their own categories.

## Want more sections?

The theme's patterns cover a standard marketing site. If you want more layout building blocks —
sliders, tabs, accordions, pricing tables, animated counters and so on — the free
[Bloqra Blocks plugin](https://beautifulplugins.com/themes/bloqra/docs/bloqra-blocks/) adds them to
the same editor, styled to match the theme.
