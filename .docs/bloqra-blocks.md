# Bloqra Blocks

The Bloqra **theme** gives you the frame of a site: templates, styles and a curated set of
patterns. **Bloqra Blocks** is the companion plugin that gives you more to put inside it —
advanced blocks for the editor you already use.

The theme is free forever, and so is the Bloqra Blocks plugin. Only the optional
[Pro add-on](#bloqra-blocks-pro) is paid.

## Installing Bloqra Blocks

**From the theme dashboard:**

1. Go to **Appearance → Bloqra → Useful Plugins**.
2. Find **Bloqra Blocks** and click **Install**, then **Activate**.

**From your plugins screen:**

1. Go to **Plugins → Add New**.
2. Search for **"Bloqra Blocks"**.
3. Click **Install Now**, then **Activate**.

It is also on [WordPress.org](https://wordpress.org/plugins/bloqra/).

## What you get for free

Bloqra Blocks adds a set of blocks the WordPress core library does not have — the layout and
marketing pieces most sites end up needing:

- Advanced containers and section wrappers
- Accordions, tabs and toggles for FAQs and long content
- Sliders and content carousels
- Pricing tables and comparison layouts
- Counters, progress bars and testimonials
- Icon lists, buttons and call-to-action blocks

Every block inherits your theme colors, typography and spacing, so anything you build with them
matches the rest of your Bloqra site without extra styling.

## How the theme and plugin fit together

They are independent, and each works on its own:

- The **theme** owns **Appearance → Bloqra** — templates, styles and theme setup.
- The **plugin** owns its own top-level **Bloqra** menu — block settings and the block library.

Nothing breaks if you use one without the other. With both active, the plugin adds a shortcut back
to the theme dashboard so you always know which screen you are on.

## Bloqra Blocks Pro

Pro is a paid add-on that installs alongside the free plugin — you keep everything you already
built, and the extra features simply appear.

It is aimed at sites that need more than layout: advanced display and visibility controls, richer
interaction and animation options, extra premium blocks, dynamic content, and priority support
from the people who build the theme.

[See what Pro includes →](https://beautifulplugins.com/plugins/bloqra/pricing/)

Buying Pro is never required to use the theme, and no Bloqra theme feature is locked behind it.
